# Supermicro X14DBI (AST2600 BMC)

Postman Collection v2.1 and Environment generated by auto-discovery against a
Supermicro X14DBI board's BMC (Aspeed AST2600, Redfish v1.22.2, firmware
`01.07.21.00`).

Unlike the hand-curated HPE iLO collections in the repository root, this was
produced automatically by crawling `/redfish/v1` and following every
`@odata.id` link, so it covers the full resource tree (813 endpoints) rather
than a curated topic subset. Regenerate it with
[postman-redfish-discovery](https://github.com/MartinYangTW/postman-redfish-discovery):

```bash
uv run redfish-discovery discover \
  --host <BMC_IP> --username ADMIN --auth basic --insecure \
  --output out/supermicro-x14dbi --csv
```

## Files

- `postman_collection.json` — GET request for every discovered resource, plus
  generated POST requests for any `Actions` found (e.g. `ComputerSystem.Reset`).
  PATCH/Action requests are for review only — the tool never sends mutations itself.
- `postman_environment.json` — variables for host/port/auth; `BMC_HOST`,
  `USERNAME`, `PASSWORD` are left blank on purpose. Fill them in locally after
  import, don't commit real values back into this file.
- `endpoints.csv` — flat list of every discovered URI, handy for a quick diff
  against another firmware version or board.

## Usage

1. Import both JSON files into Postman.
2. In the environment, set `BMC_HOST` to your target BMC's IP/hostname and
   fill in `USERNAME`/`PASSWORD` (kept as Postman "secret" type — not synced
   to Postman Cloud by default).
3. Run `1_Sessions`-style login first if you want token/session auth instead
   of Basic (this collection defaults to Basic Auth via the environment).
